# PiDesk UI 界面说明

设计原则：**键盘优先、单流对话、信息密度高**（对标 Hermes TUI / Codex），在此基础上叠加 GUI 才能提供的增强（可折叠工具卡、diff 高亮、会话树可视化、图形审批）。

## 1. 整体布局

三栏 + 顶栏 + 底部输入区的经典布局：

```
┌───────────────────────────────────────────────────────────────────────┐
│ 顶栏 TopBar: [会话名] [cwd 项目路径]        [模型▾] [思考等级▾] [tokens]  │
├──────────────┬────────────────────────────────────────┬───────────────┤
│              │                                          │               │
│  左侧栏       │            主对话流 Conversation          │  右侧栏(可折叠) │
│  Sidebar     │                                          │  Inspector    │
│              │   • 用户消息气泡                           │               │
│  • 项目/cwd   │   • assistant 流式消息(Markdown+高亮)      │  • 文件 diff   │
│  • 会话列表    │   • 工具调用卡片(可折叠)                    │  • 上下文文件   │
│  • 会话树      │   • 系统事件行(压缩/重试/换模型)            │  • 待办 widget  │
│  • 新建会话    │                                          │  • 会话统计     │
│              │                                          │               │
│              ├──────────────────────────────────────────┤               │
│              │  底部输入区 Composer                        │               │
│              │  [多行输入框  @文件 / 图片粘贴]              │               │
│              │  [模型chip][思考chip]   [中止] [发送/Steer] │               │
├──────────────┴──────────────────────────────────────────┴───────────────┤
│ 状态栏 StatusBar: ● idle/streaming  |  分支: main  |  队列: 0  |  快捷键提示 │
└───────────────────────────────────────────────────────────────────────┘
```

> 布局可响应式：窗口变窄时右侧栏自动收起，侧栏可 `Ctrl+B` 折叠，进入类似 Codex 的「纯对话流 + 输入区」极简模式。

## 2. 各区域详解

### 2.1 顶栏 TopBar

- **会话名**：可点击重命名（调 `setSessionName`）。
- **cwd**：当前会话绑定的项目目录，点击可打开系统文件管理器或切换目录。
- **模型选择器**：下拉展示 `getAvailableModels()` 结果，选择即 `setModel`；也可 `Ctrl+P` 唤起模型快速切换面板（对标 Pi 的 Ctrl+P cycle）。
- **思考等级**：`off / minimal / low / medium / high / xhigh / max` 下拉，调 `setThinkingLevel`。
- **tokens/用量**：显示 `getSessionStats()` 的 token 估算与消息数；接近上下文上限时高亮，并提示可 `/compact`。

### 2.2 左侧栏 Sidebar

- **项目切换**：最近打开的 cwd 列表；每个项目对应 `~/.pi/agent/sessions/<encoded-cwd>/` 下的会话集合。
- **会话列表**：当前项目的历史会话（读 session 目录），显示会话名 + 时间 + 首条消息摘要；点击 `switchSession` 加载。
- **会话树视图**：把 `getTree()` 渲染为可展开的树，可视化 fork/分支；点击任一用户消息节点可「从此处 Fork」（`fork(entryId)`）——这是 GUI 相对 TUI 的显著增强。
- **[+ 新建会话]**：`startSession`，可选择父会话做 lineage。

### 2.3 主对话流 Conversation（核心区）

时间线按 `TimelineItem` 顺序渲染：

1. **用户消息**：右对齐气泡，支持显示附带的 `@file` 引用与图片缩略图。
2. **Assistant 消息**：左对齐，Markdown 渲染 + shiki 代码高亮；流式期间末尾显示光标/spinner（对标 Pi 的 working indicator）；定稿后出现「复制 / 引用 / 从此处 Fork」悬浮操作。
3. **工具调用卡片**（重点增强）：
   - 折叠态：一行摘要 `⚙ bash · npm run build` + 状态点（运行中/成功/失败）。
   - 展开态：
     - `bash`：命令 + 流式 stdout/stderr（等宽字体）+ 退出码。
     - `edit`：**diff 视图**（红删绿增，行号），来自 `edits[].oldText/newText`。
     - `write`：目标路径 + 新内容预览。
     - `read/grep/find/ls`：路径/pattern + 结果列表。
   - 失败（`isError`）卡片红色描边，顶部显示错误摘要。
4. **系统事件行**：压缩（compaction）、自动重试、模型切换、会话重命名等，以低调的分隔行呈现（对标 Codex 的系统提示）。

### 2.4 底部输入区 Composer

- **多行输入框**：`Enter` 发送、`Shift+Enter` 换行（可在设置中互换）。
- **@文件 补全**：输入 `@` 触发 cwd 内文件模糊补全，插入文件引用。
- **图片**：支持粘贴/拖拽图片（映射为 `ImageContent`，随 `prompt` 发送）。
- **发送按钮的三态**（对标 Pi 的 prompt/steer/follow_up 语义）：
  - Agent 空闲 → **发送**（`prompt`）。
  - Agent 运行中 → 按钮变 **Steer**（`steer`，当前轮工具间隙插入）；旁边提供 **Follow-up**（`followUp`，排队到空闲后）与 **中止**（`abort`）。
- **内联 chip**：模型 chip、思考等级 chip，点击即改，无需上移到顶栏。

### 2.5 右侧栏 Inspector（可折叠）

- **Diff/文件预览**：点击工具卡里的文件时，在此显示完整 diff 或文件内容。
- **上下文文件**：本会话已纳入上下文的文件清单。
- **待办/Widget**：渲染扩展通过 `setWidget` 推送的挂件（如任务清单）。
- **会话统计**：token 明细、每模型用量、耗时。

### 2.6 审批弹窗 Approval Modal

当收到 `approval-request`（来自内置审批扩展）时弹出模态框：

- 标题：`允许执行 bash?`
- 主体：工具入参的**结构化展示**（bash 显示命令、edit 显示 diff 摘要、write 显示路径+大小）。
- 按钮：**允许（Enter）** / **拒绝（Esc）** / 可选「本会话内此工具始终允许」。
- 无操作超时（若扩展设了 timeout）→ 默认拒绝并提示。

### 2.7 命令面板 Command Palette

`Ctrl+K` 唤起，聚合 `getCommands()`（扩展命令 / prompt 模板 / skill）+ PiDesk 内置动作（新建会话、切换主题、导出 HTML、压缩上下文等），模糊搜索、键盘选择——对标 Codex/VS Code 的命令面板。

## 3. 快捷键（默认，可在设置中自定义）

| 快捷键 | 动作 |
|---|---|
| `Enter` | 发送 / Steer（运行中） |
| `Shift+Enter` | 输入框换行 |
| `Esc` | 中止当前运行 / 关闭弹窗 |
| `Ctrl+K` | 命令面板 |
| `Ctrl+P` | 模型快速切换 |
| `Ctrl+B` | 折叠/展开左侧栏 |
| `Ctrl+J` | 折叠/展开右侧栏 |
| `Ctrl+N` | 新建会话 |
| `Ctrl+L` | 聚焦输入框 |
| `Ctrl+/` | 插入 slash 命令 |
| `Ctrl+.` | 循环思考等级 |
| `↑ / ↓`（输入框空时） | 浏览历史输入 |

## 4. 主题与视觉

- **主题**：内置浅色/深色，直接**复用 Pi 的主题定义**（`dist/modes/interactive/theme/{light,dark}.json`）以保持与原生 TUI 一致的配色语义；跟随系统主题可选。
- **字体**：正文用系统 UI 字体；代码/终端区用等宽字体（如 Cascadia Code / JetBrains Mono）。
- **信息密度**：默认紧凑模式（对标 TUI），提供「舒适」间距选项。
- **状态色**：运行中=蓝、成功=绿、失败/危险=红、警告=黄；与审批弹窗、工具卡状态点统一。

## 5. 交互模式对标说明

| 能力 | Hermes TUI / Codex 的做法 | PiDesk 的对应/增强 |
|---|---|---|
| 主交互 | 单一对话流 + 底部输入 | ✅ 相同，默认极简模式即为此形态 |
| 运行中插话 | steer / 排队 | ✅ 发送按钮三态（发送/Steer/Follow-up） |
| 中止 | Esc / Ctrl+C | ✅ Esc + 中止按钮 |
| 命令 | slash 命令 / 命令面板 | ✅ `Ctrl+K` 命令面板聚合 `getCommands()` |
| 会话管理 | resume / 列表 | ✅ 侧栏会话列表 + **会话树可视化（增强）** |
| 工具输出 | 终端文本 | ✅ **可折叠工具卡 + diff 高亮（增强）** |
| 审批 | 终端 y/n 提示 | ✅ **图形审批弹窗（经内置扩展）** |
| 模型切换 | Ctrl+P cycle | ✅ Ctrl+P 面板 + 顶栏下拉 |

## 6. 原型

`prototype/index.html` 提供了上述布局的高保真静态原型（浅色主题），可直接在浏览器打开预览各区域的视觉与信息层级。
