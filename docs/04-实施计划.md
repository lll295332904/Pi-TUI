## 2. 迭代里程碑

### M0 — 脚手架与打通（最小可用闭环）
- `electron-vite` 初始化 Electron+React+TS 工程。
- `pi-locator` 定位本机 pi；`PiKernel` 用 `RpcClient` 启动一个会话。
- 打通「输入 → `prompt` → 流式 `message_update` → 渲染」最小链路。
- **验收**：能在 GUI 里发一句话，看到 assistant 流式回复。

### M1 — 对话流与工具可视化
- 完整 timeline 渲染：用户/assistant/系统事件行。
- 工具卡片：bash 输出、edit diff、write 预览、read/grep 结果。
- 运行状态机：streaming/idle、中止、Steer/Follow-up 三态按钮。
- **验收**：一次涉及多工具的任务能完整、可读地呈现全过程。

### M2 — 会话管理
- 侧栏项目/会话列表；`switchSession` 加载历史。
- 会话树可视化 + 从消息 Fork（`getTree` / `fork`）。
- 新建/重命名/导出 HTML。
- **验收**：可在多个会话与分支间自由切换、回溯。

### M3 — 审批与扩展 UI
- 内置审批扩展随 RPC 加载（`-e`）。
- `extension_ui_request` → 审批弹窗；`respondApproval` 回写。
- 支持 select/input/notify/setStatus/setWidget 等扩展 UI。
- 审批策略开关（自动/危险确认/全部确认）。
- **验收**：bash/edit/write 执行前可弹图形确认，拒绝能真正阻止。

### M4 — 打磨与打包
- 模型/思考等级选择器、命令面板（`Ctrl+K`）、快捷键系统。
- 浅/深主题（复用 Pi 主题）、响应式布局、极简模式。
- `electron-builder` 产出 NSIS 安装包 + portable exe。
- **验收**：可分发的 `.exe`，日常可替代 `pi` 命令行使用。

> 说明：以上为逻辑迭代顺序，不含具体工期承诺；可按需并行或裁剪（例如个人使用可先做 M0–M2，审批 M3 视需要）。

## 3. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| Pi 升级导致 RPC 协议/类型变化 | 通信层需跟进 | 锁定 `@earendil-works/pi-coding-agent` 版本；仅通过 `RpcClient` 公共 API 调用，不依赖内部实现；升级时跑一遍协议冒烟测试 |
| 协议无原生工具审批 | 无法「执行前确认」 | 已在方案中用内置扩展 + `extension_ui_request` 解决（§技术方案 5） |
| JSONL 分帧（U+2028/2029） | 消息解析错乱 | Electron 路线由 `RpcClient` 内部正确处理；Tauri 路线严格按 `\n` 分帧，禁用 readline |
| stdout 被污染 | 事件解析失败 | RPC 模式已保证 stdout 纯净、日志走 stderr；`PiKernel` 收集 stderr 供诊断 |
| exe 体积大（Electron） | 分发不便 | 默认「依赖本机 pi」不内置 Pi；或改用 Tauri 备选路线（<15MB） |
| 本机未安装/找不到 pi | 无法启动 | `pi-locator` 多路径探测 + 引导安装提示；支持手动指定 cli 路径 |
| 凭据安全 | 密钥泄露 | PiDesk 不接管凭据，沿用 Pi 的 `auth.json` / 环境变量 |
| Windows SmartScreen 警告 | 首次运行受阻 | 个人使用可忽略；必要时购证书签名 |

## 4. 后续可选增强

- 多标签/多窗口并行会话。
- 会话内全文搜索、跨会话检索。
- 与 VS Code 联动（点击 diff 跳转到编辑器对应行）。
- 语音输入、通知中心（`notify` 事件→系统通知）。
- 自动更新（electron-updater）。
